# Exercices Pandas

Ce dossier contient des exercices et des exemples pour s'entraîner avec Pandas.

Fichiers:
- `exercices_pandas.py` : script de démarrage avec des tâches courantes.

Utilisation :
1. Ouvre le script dans VS Code ou un notebook.
2. Modifie et exécute chaque section.
3. Utilise le fichier `../players.csv` si tu veux des données réelles.

Exemples d'exercices :
- Lire un fichier CSV
- Afficher les premières lignes
- Filtrer les données
- Grouper et calculer des statistiques
- Joindre des tables
