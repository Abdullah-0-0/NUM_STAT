# Entraînement Pandas et Matplotlib

Ce dossier est destiné à l'entraînement sur Pandas et Matplotlib.

Structure actuelle :
- `pandas/` : exercices et exemples d'utilisation de Pandas
  - `README.md` : guide d'utilisation et idées d'exercices
  - `exercices_pandas.py` : script de démarrage
- `matplotlib/` : exercices et exemples de tracés Matplotlib
  - `README.md` : guide d'utilisation et idées d'exercices
  - `exercices_matplotlib.py` : script de démarrage

Utilisation :
1. Ouvre les fichiers `*.py` dans VS Code.
2. Exécute-les avec Python ou convertis-les en notebook.
3. Modifie les données, les filtres et les tracés pour t'entraîner.

Tu peux utiliser le fichier `players.csv` existant dans le dossier parent comme jeu de données de test.
