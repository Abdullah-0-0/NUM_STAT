# Exercices Matplotlib

Ce dossier contient des exemples pour s'entraîner avec Matplotlib.

Fichier :
- `exercices_matplotlib.py` : script pour tracer des graphiques simples.

Utilisation :
1. Ouvre le script dans VS Code.
2. Exécute-le pour voir des graphiques.
3. Modifie les données et les styles pour t'entraîner.

Exemples d'exercices :
- Tracer une courbe
- Créer un histogramme
- Personnaliser les titres et les légendes
- Sauvegarder un graphique
